# Estructura de la Aplicación

Esta aplicación sigue una estructura de directorios organizada para facilitar el mantenimiento y la comprensión. A continuación se describen los directorios principales:

- **actividades/**: Este directorio contiene todas las actividades del proyecto, organizadas por temas o módulos.
- **css/**: Aquí se almacenan los archivos de estilos CSS que se utilizan para dar formato a la aplicación.
- **downloads/**: Este directorio es para archivos que los usuarios pueden descargar.
- **fonts/**: Aquí se encuentran las fuentes personalizadas utilizadas en la aplicación.
- **img/**: Este directorio guarda todas las imágenes utilizadas en la aplicación.
- **index.html**: Este es el archivo principal de la aplicación que sirve como punto de entrada y carga el resto de los recursos.
